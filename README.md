Descripción

Bella Luna es un salón de belleza que necesita una forma más ordenada de llevar el control de sus clientes, citas y servicios. El proyecto busca crear un sistema sencillo que facilite el trabajo de los colaboradores del salón.

Problema que resuelve

Actualmente, llevar la información de los clientes, las citas y los servicios de forma manual puede causar confusiones, pérdida de información o citas repetidas. El sistema busca ayudar a tener esta información más organizada y fácil de consultar.

Tecnologías y herramientas previstas

- Git y GitHub para guardar y llevar el control de los cambios del proyecto.
- Canva para realizar el diseño de las pantallas del sistema.
- Herramientas web para continuar con el desarrollo del sistema en los siguientes proyectos.
